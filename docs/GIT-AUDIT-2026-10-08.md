# Git re-audit — 2026-10-08

The repository was re-read from GitHub main before Batch 80.

Confirmed foundations:
- Next.js 16.3.8 / React / TypeScript web app
- PostgreSQL + Drizzle data layer
- Auth.js credentials/JWT authentication
- calculator package with production tests
- public tool catalog and dynamic tool pages
- calculator publication workflow, audit/change history and persisted RBAC
- customer/admin application shells
- account-owned saved calculator result persistence
- immutable Drizzle migrations through 0003 before this batch

Important findings:
1. Admin workspace access currently reuses calculator publication permissions.
   It is protected, but a dedicated platform-admin permission model is still
   required before calling global admin RBAC complete.
2. Publication readiness/mutation still hardcode formula requirements. The
   repository also contains dataset-driven calculator architecture (notably
   Digital SAT), so publication policy needs a shared engine-aware requirement
   resolver in a following backend-integrity batch.
3. Public calculator evidence selection should receive another deterministic
   review for formula/source/review ordering and completed-review filtering.
4. Generic dashboard callback URLs were derived from display labels. Batch 80
   corrects the shared primitive to require an exact route path.
5. Customer Study Plan, Progress and Settings were still placeholder routes.
   Batch 80 promotes all three to persisted account functionality.
6. Analytics/SEO/monetization/content/support admin sections remain foundations,
   not completed operational modules.
7. Forgot/reset/verify pages exist, but email delivery and full recovery flow
   must not be considered complete until connector/provider delivery is wired
   and runtime-tested.

No claim is made that the platform is production-complete; this audit is used
to prioritize the next implementation batches.
