# Batch 152 — schedule templates and printable planner

Cumulative release based on Batch 151 Fix 1. Adds five local schedule templates, a standalone printable HTML planner, and 12 automated tests. The planner escapes dynamic content, includes no remote assets, and never records study activity. All previously available TXT, JSON, CSV and ICS exports remain available. No new dependencies or database migrations. Run database/calculator tests, typecheck, lint and production build on the complete local monorepo.
