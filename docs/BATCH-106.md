# Batch 106 — Direct saved-history page navigation

Adds an accessible GET form to jump to a specific saved SAT/ACT result history page. The form is only shown for multi-page results and retains validated exam, date, sort, and page-size parameters. The server-side history query continues to bound and clamp page inputs. Uses existing dashboard styles, no JavaScript, dependencies, or migrations.
